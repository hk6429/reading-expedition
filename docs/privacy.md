# 隱私與匿名成效事件

《萬卷浮城》採本機優先。不建立家庭護照時，閱讀位置、個人城市、收藏、裝備與偏好只留在使用者裝置。

家庭護照是家長選配的跨裝置功能。建立後，伺服器只保存護照碼雜湊、孩子代號、分級與模式偏好、結構化閱讀診斷、城市及裝備狀態；不同孩子以家庭與孩子雙重邊界隔離。系統無法判定孩子代號是否為真名，請勿輸入真名、Email、學校、班級或學號；系統不接收自由反思與作答文字。護照明碼只在建立當下顯示一次，網站不替家長保存。

家庭報告以孩子當地時區計算週趨勢，先顯示卡關能力與下一步；CSV 可分別匯出單一孩子與全家庭彙整資料。

伺服器只接收八種固定事件、客戶端隨機事件 UUID 與五個結構化欄位：內容 ID、主題類別、難度、耗時區間、35 日輪替的隨機匿名統計代碼。統計預設關閉，只有使用者明確同意後才會傳送；拒絕不影響任何閱讀功能。事件格式沒有姓名、學號、Email、學校、班級真名、作答文字、自由反思或裝置指紋欄位；系統也無法由代碼內容判定是否含有真實身分，請勿把身分資料填入任何代號欄位。

班級碼在伺服器只保存不可逆雜湊。教師建立班級時，明碼只回傳一次並暫存在目前教師分頁；停用班級時，既有匿名參與權杖會同步失效。

班級共同任務只接受伺服器簽發的短效、一次性完成證明。學生投票與結束單都使用固定代碼，不收自由文字；教師只在至少五位匿名參與者時看到群體分布。學習品質只彙總首次正確、修正成功、查看文證與完成遷移四個比例，不回傳個別學生或答案。參與權杖每分鐘最多計入 3 次，班級每分鐘最多 120 次，重複文章、重播或過期證明不計入。

匿名事件只用於檢查閱讀設計是否真正促進「完成閱讀並找到文證」，不建立個人排名、不做廣告輪廓，也不以速度判定學習成效。原始匿名事件最多保留 45 天；超過期限會由排程刪除，只保留達隱私門檻的彙總結果。
