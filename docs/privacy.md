# 隱私與匿名成效事件

《萬卷浮城》採本機優先。不建立家庭護照時，閱讀位置、個人城市、收藏、裝備與偏好只留在使用者裝置。

家庭護照是家長選配的跨裝置功能。建立後，伺服器只保存護照碼雜湊、孩子代號、分級與模式偏好、結構化閱讀診斷、城市及裝備狀態；不同孩子以家庭與孩子雙重邊界隔離。系統拒收真名、Email、學校、班級、學號、自由反思與作答文字。護照明碼只在建立當下顯示一次，網站不替家長保存。

家庭報告以孩子當地時區計算週趨勢，先顯示卡關能力與下一步；CSV 可分別匯出單一孩子與全家庭彙整資料。

伺服器只接收八種固定事件與五個結構化欄位：內容 ID、主題類別、難度、耗時區間、隨機匿名裝置 ID。系統拒收姓名、學號、Email、學校、班級真名、作答文字、自由反思、裝置指紋與額外欄位。

班級碼在伺服器只保存不可逆雜湊。教師建立班級時，明碼只回傳一次並暫存在目前教師分頁；停用班級時，既有匿名參與權杖會同步失效。

匿名事件只用於檢查閱讀設計是否真正促進「完成閱讀並找到文證」，不建立個人排名、不做廣告輪廓，也不以速度判定學習成效。
