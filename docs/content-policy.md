# 內容治理政策

1. 只從核准來源白名單擷取標題、短摘要與可追溯事實；不把 RSS 視為全文改寫授權。
2. 新聞、爭議與高敏感題材必須使用至少兩個獨立原始來源。
3. 數字、日期、人名、單位、來源授權或事實互相衝突時，停止生成並送人工處理。
4. 戰爭、災難、死亡、犯罪、性別暴力、政治及重大健康題材永遠人工校閱。
5. 前 30 個正式日全部人工審核；其後也只有硬門檻全數通過且品質達 92 分的非敏感稿件可自動發布。
6. 來源失效或授權條件改變時停止新產出；已發布內容須能下架，學生既有城市成果不得因此消失。
7. 生成內容與題目必須能回到發布文字中的明確文證，不得加入來源沒有的事實。
