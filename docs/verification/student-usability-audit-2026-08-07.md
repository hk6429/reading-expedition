# 四位國中生使用評測與修正紀錄

- 評測日期：2026-08-07
- 評測範圍：首次進站、備份、測讀、閱讀、答題、書架、家庭同步、浮城與離線情境
- 完成標準：每位學生提出 10 點，共 40 點；每點都對應可驗收的修正或明確的隱私取捨

## 七年級學生：第一次使用與閱讀操作

1. 更新後偶爾混到舊模組，畫面與程式版本不一致。修正：Service Worker 改為 network-first、清除舊版快取並升版至 v15。
2. 從書籤直接進文章會略過備份提醒。修正：除家庭與教師頁外，每條學生路由第一次進入都先顯示提醒。
3. 共用裝置只寫「這位閱行者」，不知道紀錄屬於誰。修正：提醒框顯示目前孩子代號或明確標成此裝置紀錄，並提示共用者先切換家庭成員。
4. 「我已確認」不清楚確認了什麼。修正：按鈕改成「這次先不備份，開始閱讀」，下載動作則明寫 JSON 備份。
5. 五分鐘測讀與自己選程度看起來互相衝突。修正：說明測讀只提供建議、不鎖級，未測讀時標示目前暫從啟航開始。
6. 切換程度或引導模式後畫面跳回頂端。修正：儲存偏好後回復原捲動位置。
7. 手機頂端連結太多。修正：保留三個主要入口，其餘收進「更多」選單。
8. 文內詞語按鈕太小。修正：觸控裝置的點擊高度提高到至少 48px。
9. 還沒讀文章就能直接答題。修正：未抵達最後一段前鎖住答題按鈕，並顯示尚需完成的閱讀步驟。
10. 系統說「回到精確位置」，實際只回到段落。修正：文案改成回到上次段落；接近文末時改提示可重新確認結尾。

## 八年級學生：答題門檻與失敗後再挑戰

11. 閱讀進度可能因重新開啟而倒退。修正：只保存較大的進度，不以較小的新值覆寫。
12. 快速滑過最後一段就算讀完。修正：抵達文末後需停留，才開放答題。
13. 已讀到 95% 但未完成時，再開文章沒有續讀提示。修正：只要未達標且有進度就提供續讀，不再用 95% 隱藏。
14. 閱讀頁看不出目前是引導或獨立模式。修正：頁首持續顯示模式標籤。
15. 想在文章中切換引導／獨立模式，原本找不到入口。修正：閱讀控制列加入模式切換並立即保存。
16. 作答前不知道幾題才算通過。修正：題目頁明示「三題答對兩題達標」。
17. 第一次已答對 2／3 題，系統仍強迫修正錯題。修正：達標即開放完成，不再強迫全對。
18. 離開未送出的答案會無聲消失。修正：離頁與關閉視窗前警告；基於隱私，不把原始選項文字長期存進瀏覽器。
19. 未達標完成後只知道分數，不知道卡在哪種能力。修正：列出找重點、想意思、找證據的最終結果與下一步。
20. 答過但未達標的文章在首頁仍顯示「未讀」。修正：顯示「已作答、待再挑戰」與目前答對題數。

## 九年級學生：診斷、紀錄與資訊查找

21. 備份提醒出現後，鍵盤焦點仍停在背景首頁。修正：使用原生 modal dialog，焦點移到提醒標題並禁止 Escape 略過。
22. 測讀只顯示總分，看不出弱項。修正：結果拆成找重點、想意思、找證據三項診斷。
23. 測讀送出後焦點留在已隱藏的表單。修正：把焦點移到結果標題並用即時狀態宣告。
24. 推薦程度像是已替學生決定。修正：結果只提供三個可選起點，不自動改掉目前程度。
25. 書架看不到每篇的答題成果。修正：完成文章顯示答對題數、日期；未達標顯示最近一次分數。
26. 同一天重做診斷會覆寫前一次。修正：診斷紀錄改為 append-only，保留嘗試次數與完成時間。
27. 文章變多後，書架沒有搜尋。修正：加入標題與問題關鍵字搜尋。
28. 書架不能依需求縮小範圍。修正：加入世界／科學／人文及閱讀分鐘篩選，保留只看未讀。
29. 完成引導版後切獨立模式，書架仍強制打開舊模式。修正：顯示目前偏好版本，同時沿用同主題完成狀態。
30. 線上文章雖曾讀過，離線時不一定能批改。修正：清楚標示需連線批改；只有本機具有答案鍵的文章才允許離線答題。

## 共用裝置學生：備份、家庭切換與浮城回顧

31. 備份提醒只是橫幅，仍能點背景。修正：改成阻擋背景操作的原生對話框。
32. 提醒框沒有說目前備份的是哪份紀錄。修正：加入目前紀錄識別標籤。
33. 備份檔名只有日期，家中多人容易拿錯。修正：檔名加入安全化的孩子代號或「此裝置」。
34. 下載成功或失敗都沒有回饋。修正：加入可讀狀態訊息；下載失敗時不關閉提醒框。
35. 家庭同步衝突只叫人備份，附近沒有按鈕。修正：衝突區直接提供目前孩子 JSON 備份。
36. 複製護照碼失敗時沒有替代辦法。修正：攔截剪貼簿錯誤並提示手動選取複製。
37. 手機輸入護照碼容易被自動改字或拼字校正。修正：關閉拼字校正、保留字元輸入並補上格式說明。
38. 刪除目前孩子後，本機仍留著他的進度。修正：刪除目前孩子時同步清空本機學習狀態。
39. 「登出」會讓下一位使用者誤以為本機已清空。修正：拆成「登出但保留」與需確認的「登出並清除此裝置紀錄」。
40. 浮城事件簿只有文證，看不到當篇答題成績。修正：最近文證旁顯示答對題數與達標狀態；投資後焦點也移到成長結果。

## 隱私與產品取捨

未送出的逐題選項不做長期保存，避免共用裝置殘留原始作答內容；改以離頁警告防止誤失。已送出的診斷只保存題型、對錯、修正與是否查看文證，不保存姓名或自由文字答案。
