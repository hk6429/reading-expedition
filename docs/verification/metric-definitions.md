# 成效指標定義

- 有效閱讀：同一匿名裝置、同一內容同時具有 `reading_completed` 與 `evidence_located`。
- D1／D7／D30：首次活躍後第 1／7／30 天再次出現核准事件的匿名裝置比例。
- 文證一致率：找到文證且完成閱讀的內容數，除以作答送出數。
- 回航率：在觀察期內有兩次以上有效活動的匿名裝置比例。
- 快速提交率：耗時區間為一分鐘以下的作答事件比例，只作為副作用警示。
- 固定選項率：只在彙總層計算，不保存個別答案；若明顯偏高，視為猜答風險。

版本判定必須同時兼顧完成率與文證一致率。即使完成率提高，只要文證一致率下降，就不得宣告新版成功。
