# 上線安全檢核

- [ ] URL 僅接受 HTTP(S)、完整 hostname 白名單與白名單內重新導向。
- [ ] localhost、私網、雲端 metadata、超大回應與逾時皆被阻擋。
- [ ] 外部文字只進入不受信任資料欄位，不能改寫系統提示。
- [ ] 教師端點使用雜湊密鑰、安全 cookie、到期、撤銷與 CSRF。
- [ ] 班級碼只保存雜湊；建立與停用須通過教師 session 與 CSRF，停用同步撤銷學生權杖。
- [ ] 未授權請求不能讀取草稿、答案、來源稽核內容或執行發布／下架。
- [ ] API、HTML、前端 bundle 與 build log 不含 secrets。
- [ ] 匿名事件拒收個資、自由文字、答案與裝置指紋。
- [ ] 來源失效、授權改變與內容下架均有明確處置。
- [ ] 行動版必要資產與快取命中 API 符合效能預算。
- [ ] 320、390、600、768px 直向及 1024×768 橫向完成主要流程。
