# 萬卷浮城來源政策

## 原則

系統只擷取事前登錄的白名單來源。每筆素材必須保存 canonical URL、發布者、發布日期、擷取時間、授權快照、允許用途與實際擷取範圍，否則不得進入事實包。

## 允許的使用方式

- 優先使用政府開放資料、公領域資料與明確標示開放授權的內容。
- RSS 僅視為「標題、短摘要、連結」的索引來源，不等於取得全文重製權。
- 來源允許摘要時，系統仍只抽取可核對的事實，不複製原文段落來改寫。
- 每一項主張需保留來源項目 ID，讓教師能回到原始資料核對。

## 技術防線

- 只允許 HTTP(S)，並拒絕 localhost、私有 IP、非白名單主機及跨白名單重新導向。
- 每個 adapter 有 8 秒逾時、512 KB 回應上限與可判讀錯誤碼。
- 單一來源或單一資料列失敗時隔離處理，不拖垮其他來源。
- 以 canonical URL 與正規化內容指紋去重。

## 發布界線

來源登錄不代表文章可以自動發布。事實衝突、授權不清、敏感主題、缺少第二來源或品質分低於 92 分時，一律送回人工校閱。
