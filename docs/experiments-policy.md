# 兒少閱讀實驗安全政策

《萬卷浮城》只允許已明確同意匿名統計者進入低風險介面實驗。變體只能改善說明、排版、導航與學習鷹架；不得測試倒數、限時獎勵、損失文案、排行榜、抽卡、稀有度、通知壓力、隱私預設、退出能力或無障礙功能。

每項實驗開始前必須登錄：教育假設、主要學習指標、福祉與無障礙護欄、最低樣本數、最低觀察期間、預期最小效果、停止規則與回滾負責人。未達樣本或觀察期一律標記為資料不足。

發布依內部、1%、10%、50% 分階進行。只要純鍵盤完成率下降、離線失敗率上升、未達標復歸率下降，或任何兒少福祉護欄惡化，就立即停止變體並恢復基線。不得以 D1、D7、D30、使用時長或完成篇數單獨宣告成功。
