# 梁山閱征記：四位閱讀專家 30 項改善方案

本方案整合四個角色的獨立審查：國中閱讀評量、青少年手機閱讀、大量閱讀與習慣、資訊素養與策展。重複問題已合併，因此清單固定為 30 項，不以相似說法重複計數。

狀態定義：

- `本輪完成`：已在本輪落地並有自動測試或畫面驗收。
- `既有基礎`：網站已有核心結構，本輪補強或保留。
- `下一階段`：需要新增內容模型、資料結構或較大互動，另排版本。

## 本輪選用的網站積木

- 展示層：緊湊航線卡、閱讀前導問、段落進度、續讀卡、精準文證抽屜。
- 邏輯層：最近已發布內容回退、全部錯題修正隊列、固定基本成長回饋。
- 記憶層：沿用本機閱讀位置，不增加姓名、自由文字或追蹤個資。
- 版本層：服務工作程式快取版本更新，避免手機停留舊版。
- 部署層：同一份 `dist` 同步發布 Cloudflare Pages、Vercel、Netlify，API 由 Cloudflare Worker 提供。

## 本輪完成邊界

本輪先完成會造成死路、漏讀、失去閱讀目的或不公平回饋的 P0 問題，並補上手機的選書與閱讀節奏。需要新內容資料模型的書庫、來源雷達、跨文本任務、札記與習慣提示保留在下一階段，避免用只有外觀、沒有真資料的空功能冒充完成。
